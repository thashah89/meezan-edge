## 🚀 Quick Start (3 Steps)

### Step 1: Install Dependencies

```bash

```

### Step 2: Initialize Database

```bash

```

### Step 3: Run the App

```bash

```

**Option B: Run directly**
```bash

```

**Option C: Run Streamlit directly**
```bash

```
